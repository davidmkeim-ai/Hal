# HAL Teams App Package

This folder contains the starter Teams app package for HAL.

## Before sideloading

Replace the placeholder values in [manifest.json](C:\Users\dmk\OneDrive - RW Supply + Design\Personal Assistant App\appPackage\manifest.json):

- Teams app `id`
- `developer` URLs
- `contentUrl` and `websiteUrl`
- `validDomains`
- `webApplicationInfo.id`
- `webApplicationInfo.resource`

## Packaging

Zip these three files together at the root of the zip:

- `manifest.json`
- `color.png`
- `outline.png`

Then upload the zip to Teams as a custom app package.
